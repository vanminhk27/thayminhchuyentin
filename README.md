# Thầy Minh Chuyên Tin

Website cá nhân giới thiệu Thầy Nguyễn Văn Minh, các chương trình đào tạo, thành tích học sinh và bản demo khu vực Luyện Code.

## Chạy trên máy

```bash
npm install
npm run dev
```

Mở: http://localhost:3000

## Build kiểm tra

```bash
npm run build
```

## Hình ảnh

- `public/images/logo.png`: logo thương hiệu
- `public/images/banner.png`: banner
- `public/images/teacher.jpg`: ảnh thầy Minh
- `public/images/achievements/`: ảnh thành tích học sinh

## Lưu ý

Khu vực `/problems` và trang chi tiết bài tập hiện là giao diện demo. Chưa chạy code C++/Python thật trên server. Khi làm Online Judge thật cần tách worker/sandbox riêng.

### Windows nhanh nhất

Có thể double-click `start-dev.bat`. File sẽ tự `npm install` nếu chưa có thư viện, sau đó chạy website tại http://localhost:3000.
